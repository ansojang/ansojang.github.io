📊 스테이블랩 계산기

최고가·최저가만 넣으면 어떤 종목이든 동일하게 계산 · 각 차시 매도 시 실수익률까지

시드를 넣으면 이 금액으로 지금 차시수가 가능한지, 부족하면 최대 몇 차시까지 되는지 알려드립니다.
%
갭%를 넣으면 최고가 기준으로 최저가를 자동 계산. 가격을 직접 넣으면 갭%가 자동 표시.
$
실수익 보정 = 수수료·세금만큼 매도가를 올려 입력 마진이 실수익으로 그대로 나오게. 총액 그대로 = 매수가에 마진만 더함.
💡 코인(DT)에서 '금액 고정'은 차시당 남길 순이익(원)입니다 — 예: 10 넣으면 1회 순이익 10원.
통화 전환 시 자동 반영 — 달러: 0.25/0.25/0.00206% · 원화: 0.015/0.015/0.2% · 코인(코인원): 0.2/0.2/0%. 필요하면 직접 수정 가능.
